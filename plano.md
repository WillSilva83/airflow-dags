# Objetivo 

- Criar uma estrutura inicial de DAGs para o airflow 3.2.2 a fim de testar novas funcionalidades, a ideia é criar um repositório que represente as DAGs do mais simples ao mais complexo.
- Estruturar um motor de geração de DAGs onde com base em YAML (o layout do YAML será definido posteriormente.) gerará N Dags associadas, inclusive dependência entre tasks e passagem infomações entre DAGs utilizando Assets definidos. 
- Os principais projetos nesse Airflow serão do tipo de engenharia de dados - ELT em sua maioria. 
 

## Informações importantes 
- O repositório estará no github. 
- A infraestrutura do airflow rodará em uma EC2 na AWS em um docker compose já criado no projeto.
